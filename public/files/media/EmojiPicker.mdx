# EmojiPicker

A component for selecting emojis from a categorized list, including search and recent options.

### **Import**
```tsx
import { EmojiPicker } from '@app-studio/web';
```

### **Default**
```tsx
import React from 'react';
import { EmojiPicker } from '../EmojiPicker';

export const DefaultEmojiPicker = () => (
  <EmojiPicker
    label="Choose an emoji"
    placeholder="Select an emoji"
    onChange={(emoji) => console.log('Selected emoji:', emoji)}
    onEmojiSelect={(emoji) => console.log('Selected emoji object:', emoji)}
  />
);
```

### **Controlled**

```tsx
import React, { useState } from 'react';
import { Vertical, Horizontal } from 'app-studio';
import { EmojiPicker } from '../EmojiPicker';
import { Button } from '../../Button/Button';
import { Text } from 'app-studio';

export const ControlledEmojiPicker = () => {
  const [isOpen, setIsOpen] = useState(false);
  const [selectedEmoji, setSelectedEmoji] = useState('🎉');

  return (
    <Vertical gap={16}>
      <Text fontWeight="bold">Controlled EmojiPicker</Text>

      <EmojiPicker
        label="Controlled Emoji Picker"
        value={selectedEmoji}
        isOpen={isOpen}
        onChange={setSelectedEmoji}
        onOpen={() => setIsOpen(true)}
        onClose={() => setIsOpen(false)}
        closeOnSelect={false}
        placeholder="Controlled picker"
      />

      <Horizontal gap={8}>
        <Button variant="outline" onClick={() => setIsOpen(!isOpen)}>
          {isOpen ? 'Close' : 'Open'} Picker
        </Button>

        <Button variant="outline" onClick={() => setSelectedEmoji('😀')}>
          Set Happy
        </Button>

        <Button variant="outline" onClick={() => setSelectedEmoji('❤️')}>
          Set Heart
        </Button>

        <Button variant="outline" onClick={() => setSelectedEmoji('🚀')}>
          Set Rocket
        </Button>
      </Horizontal>

      <Text fontSize="14px" color="color-gray-600">
        Selected emoji: {selectedEmoji}
      </Text>
    </Vertical>
  );
};
```

### **FormIntegration**

```tsx
import React, { useState } from 'react';
import { Vertical, Horizontal } from 'app-studio';
import { EmojiPicker } from '../EmojiPicker';
import { TextField } from '../../Form/TextField/TextField';
import { Button } from '../../Button/Button';
import { Text } from 'app-studio';

export const FormIntegrationEmojiPicker = () => {
  const [title, setTitle] = useState('');
  const [emoji, setEmoji] = useState('');
  const [description, setDescription] = useState('');

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    alert(`Title: ${emoji} ${title}\nDescription: ${description}`);
  };

  return (
    <form onSubmit={handleSubmit}>
      <Vertical gap={16} width="400px">
        <Horizontal gap={12} alignItems="end">
          <EmojiPicker
            label="Icon"
            value={emoji}
            onChange={setEmoji}
            size="md"
            placeholder="Pick an icon"
          />

          <TextField
            label="Title"
            value={title}
            onChange={(e) => setTitle(e.target.value)}
            placeholder="Enter title"
            style={{ flex: 1 }}
          />
        </Horizontal>

        <TextField
          label="Description"
          value={description}
          onChange={(e) => setDescription(e.target.value)}
          placeholder="Enter description"
          helperText="Add a description for your item"
        />

        {/* Preview */}
        {(emoji || title || description) && (
          <Vertical
            gap={8}
            padding="16px"
            borderRadius="8px"
            backgroundColor="color-gray-50"
            borderWidth="1px"
            borderStyle="solid"
            borderColor="color-gray-200"
          >
            <Text fontWeight="bold">Preview</Text>
            <Text fontSize="18px" fontWeight="600">
              {emoji} {title || 'Untitled'}
            </Text>
            {description && <Text color="color-gray-600">{description}</Text>}
          </Vertical>
        )}

        <Horizontal gap={8}>
          <Button  variant="filled">
            Create Item
          </Button>
          <Button
            type="button"
            variant="outline"
            onClick={() => {
              setTitle('');
              setEmoji('');
              setDescription('');
            }}
          >
            Clear
          </Button>
        </Horizontal>
      </Vertical>
    </form>
  );
};
```

## Shared catalogue and reactions

`DefaultEmojiData`, `QuickReactionEmojis`, `Emoji` and `EmojiCategory` are exported from the package. The catalogue combines the library, document editor and conversation palettes, preserving complete Unicode sequences. Search includes French and English keywords, ignores accents and searches all enabled categories. A custom emoji with the same exact Unicode string replaces its built-in record.

```tsx
import React, { useState } from 'react';
import { EmojiPicker } from '@app-studio/components';

export const Reactions = () => {
  const [selected, setSelected] = useState(['👍']);
  return <EmojiPicker mode="reaction" selectedEmojis={selected} onChange={emoji =>
    setSelected(previous => previous.includes(emoji) ? previous.filter(item => item !== emoji) : [...previous, emoji])
  } />;
};
```

`mode` defaults to `picker`. Reaction mode opens a compact row with 👍 ❤️ 🙌 😂 😢 😮 and a More button. Set `quickEmojis` to customize the row, `selectedEmojis` to indicate your active reactions, and `trigger` to supply trigger content. Counts, requests and pending state belong to the application; use `isDisabled` while a request is pending. Recent selections are disabled by default in reaction mode.

Use `labels` to translate the search, trigger, category and empty-state text. Web panels render in a portal, stay within the viewport and support keyboard navigation and Escape. Native panels use ActionSheet. Existing `value`, `onChange`, `onEmojiSelect`, controlled opening and Formik usage remain supported.
