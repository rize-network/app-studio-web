# BlockEditor

A Markdown block editor built from App Studio primitives, without an external editor engine.

```tsx
import React, { useState } from 'react';
import { BlockEditor } from '@app-studio/components';

export const DocumentEditor = () => {
  const [markdown, setMarkdown] = useState(
    '# My document\n\nStart writing here.'
  );
  return (
    <BlockEditor label="My document" value={markdown} onChange={setMarkdown} />
  );
};
```

Use `defaultValue` for an uncontrolled editor. `onChange` receives the Markdown string. Loading a different controlled `value` clears undo history and invalidates pending AI proposals; echoing the emitted value keeps the cursor and history.

To display this value without editing controls and with activatable links, use `<Markdown value={markdown} />`. See [Markdown](./Markdown.mdx) for display syntax, native navigation and source fallback. Read-only rendering supports additional syntax; that does not enable visual editing of it.

## Blocks and editing

The block menu supports paragraphs, headings 1–3, bulleted and numbered lists, quotes, fenced code, and pipe tables. Type `/` in an empty block to open it. The block handle offers insertion, transformation, duplication, deletion and movement. Web dragging starts only from the handle, with a full-block preview. Neighboring blocks shift during dragging and a reserved gap matches the dragged block height. The preview leaves Markdown unchanged until drop, which creates one undoable transaction. Motion is disabled when reduced motion is preferred. Native provides move-up and move-down buttons.

Select text to apply bold, italic, underline, strikethrough, inline code or a link. Underline is serialized as the inert Markdown extension `<u>…</u>`. Code blocks use a monospace input and never execute code. Only http, https, mailto, tel and relative links are accepted by the link action.

The source is unchanged until an edit occurs, and editing a block leaves other blocks' source intact. Unsupported constructs, including images, MDX components, frontmatter, HTML, reference links, footnotes, task lists and nested block constructs, open in source mode. This is a bounded Markdown editor, not a full CommonMark or MDX implementation.

Select text to open the floating formatting toolbar. Its opaque surface, border and shadow separate it from the document; its position is clamped to the viewport using its actual size. It stays open while you use its controls or search for an emoji, preserving the selected text. The emoji trigger is a centered icon. Block handles are larger and remain visible. Blocks themselves have no blue focus border.

## Clipboard, selection and keyboard on web

| Shortcut                   | Behavior                                                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Ctrl/Cmd+A                 | Select the whole document from a visual text block, including code and tables. In the source textarea, use the platform's field selection. |
| ← / →                      | Move by visible character, including composed emojis, and cross block boundaries.                                                          |
| ↑ / ↓                      | Move by visual line, retaining the horizontal position through shorter blocks.                                                             |
| Shift+arrows               | Extend or shrink the selection across blocks; reversing direction keeps its original anchor.                                               |
| Enter                      | Split a prose block; continue list items; insert a newline in code or a line break in a table cell.                                        |
| Shift+Enter                | Insert a line break inside the current prose block.                                                                                        |
| Backspace at block start   | Merge with the previous block and keep the cursor at the join; tables remain separate.                                                     |
| Ctrl/Cmd+C                 | Copy the selection as Markdown, preserving block syntax when the whole document is selected.                                               |
| Ctrl/Cmd+X                 | Cut the selection in one undoable transaction. Empty inline formatting markers are removed with their selected text.                       |
| Ctrl/Cmd+V                 | Paste plain-text Markdown over the selection. HTML is never imported or executed.                                                          |
| Ctrl/Cmd+Z                 | Undo typing or a command, with cursor/selection restoration.                                                                               |
| Ctrl/Cmd+Shift+Z or Ctrl+Y | Redo.                                                                                                                                      |
| Ctrl/Cmd+B, I, U           | Bold, italic or underline. Multi-block formatting preserves headings, list markers, code fences and table separators.                      |
| Ctrl/Cmd+K                 | Open the anchored link popover with focus in the address field.                                                                            |
| Ctrl/Cmd+S                 | Call the optional `onSave` callback.                                                                                                       |
| Ctrl/Cmd+Shift+A           | Open selection AI when `generate` is provided.                                                                                             |
| Escape                     | Close the current panel or selection toolbar.                                                                                              |

Enter splits a prose block at the cursor or replaces its selection with a block boundary. Headings continue as a paragraph; quotes keep their style when split in the middle. Inline formatting and links remain balanced on both sides. Empty blocks at the start or end remain editable. Each split and merge is one undoable command, restoring the cursor.

Backspace at the first visible position joins a block to the previous one and places the cursor at the join. The previous block keeps its style. Code merged into prose stays inline code, and prose merged into code becomes literal text. Tables retain their cell boundaries and do not merge into neighboring blocks.

Enter continues bullet/numbered list items; an empty nested item outdents, and an empty top-level item exits the list. Backspace at the start of a following list item joins it to the previous item and updates later numbering. Shift+Enter inserts a line break inside a prose block. Enter in code inserts a literal newline; inside a table cell it inserts a line break. Source mode retains native textarea behavior.

The link popover uses the selection position instead of the bottom of the document. Its opaque surface, border and shadow match the floating toolbar. The target selection stays frozen while the address has focus, including when its text is selected. Enter or Apply inserts the link; Escape or Close restores the original selection; clicking outside dismisses it without stealing focus. Invalid URLs stay visible in the popover, and external document replacements close it. The panel follows scrolling/resizing and stays within the viewport.

Use Ctrl on Windows/Linux and Cmd on macOS. Copy, cut and paste use the browser's clipboard events, so context-menu actions work too. Typing, deletion, paste or IME input can replace a multi-block selection without modifying another editor on the page. An HTML-only clipboard does not erase the selected text.

On web, code uses the same contentEditable selection surface as other visual blocks, with literal monospace text and preserved Markdown fences. Selections can pass through code, lists and table cells. The floating toolbar remains available for a text selection. Source fields retain native arrow selection; Alt/Ctrl/Cmd navigation is delegated to the platform. Cross-block arrows use `Intl.Segmenter` to preserve composed characters; engines without it retain native arrow handling.

Source and code fields share the editor's undo history, including the direction of restored selections. Link fields, AI prompts, emoji search and command search retain their own native text-editing shortcuts. Undo history holds the last 100 transactions; consecutive typing is grouped over 750 ms, and moving the cursor starts a new group.

## Optional AI

```tsx
import React from 'react';
import { BlockEditor } from '@app-studio/components';

export const SimulatedAIEditor = () => (
  <BlockEditor
    label="AI demo"
    defaultValue="Select a sentence to change."
    generate={async (prompt, fragment, scope) =>
      `${fragment}\n\nSuggestion: ${prompt}`
    }
  />
);
```

The example is simulated and sends no network request. Your application supplies `generate(prompt, fragment, scope)`, returning `Promise<string>`; scope is `selection` or `section` (the whole editor). The library previews the result and requires Apply before changing the document. Errors, cancellation, empty responses and stale proposals preserve the current text. Without `generate`, AI actions are hidden.

On web, document and selection AI use the same anchored, opaque popover as link editing, including source mode. The insertion/selection target stays frozen while the prompt has focus. The popover follows scrolling and resizing and reclamps when loading, errors or a proposal change its size. Escape or Discard restores the original selection; clicking outside dismisses without stealing focus. Apply keeps the selection produced by its undoable edit. Native retains the ActionSheet.

The primary `/blockeditor` and `/markdown` catalog editors supply the same explicitly simulated callback. The document AI action is in the main toolbar; selection AI appears after selecting text (or in the source toolbar). To connect a real LLM, supply `generate` from your application's authenticated service and return only its proposed Markdown. Provider configuration, credentials, requests and authorization belong to the application; this component has no provider settings or hidden network calls.

## Images, video and optional upload

The media toolbar action opens an anchored panel on web and an ActionSheet on native. Choose image or video, a URL and a description. Images insert `![description](url)`; videos insert a standalone `[description](url "video")` paragraph. The panel explains before insertion that media uses source editing. Existing source, including code/table selections, is retained; syntax inserted inside code remains literal code. There is no atomic media editing surface.

URLs work without an upload callback. To offer file selection on web, supply:

```tsx
<BlockEditor
  value={markdown}
  onChange={setMarkdown}
  uploadMedia={async (file, { signal }) => {
    // Your authenticated storage service; return a durable http(s) or relative URL.
    return applicationUpload(file, { signal }); // { url, type: 'image' | 'video' }
  }}
/>
```

`EditorMediaFile` is a web `File` or a native `NativeMediaDescriptor` (`uri`, `name`, MIME `type`, optional `size`). `EditorMediaResult` contains `url` and `type: 'image' | 'video'`. These types are exported. On native, provide both `uploadMedia` and `pickMedia: () => Promise<EditorMediaFile | null>` using your application's real picker; `null` cancels normally. Without a picker the native upload button is hidden, and URL insertion remains available. No picker, storage vendor or runtime dependency is bundled.

One selected image/video is uploaded at a time. Loading, Cancel, error and manual Retry are visible; a retry calls the callback again. A valid success inserts once at the selection captured before the panel opened, as one undoable change. Editing, external content replacement, locking, closing and unmounting invalidate the pending operation. Cancellation aborts its signal and ignores any late result. Echoing the same controlled content does not invalidate it. Rejected MIME types, invalid destinations and failures preserve the document. The application must enforce file/content limits and storage permissions; a client MIME label is not a security boundary. No placeholder, blob URL or selected file bytes are persisted by this component.

The catalog uses a real user file selection with a **simulated upload callback**: selected bytes are never sent or stored. It waits briefly and inserts a fixed example image or video URL, regardless of the selected file's content. This demonstrates the callback and cancellation, not durable storage.

## React Native

The same component and Markdown contract work on React Native. Inactive blocks render visually; the active block uses a native multiline input showing its Markdown markers. Menus and AI proposals open in an ActionSheet. Selection formatting operates inside the active input. Enter in prose uses the shared split command; Backspace at the start of the active Markdown input merges with the preceding block. Code and table inputs retain their source editing behavior. No DOM, browser editor or WebView is required.

## Other props

`isReadOnly` renders a non-editable document. `isDisabled` disables every mutation, including toolbar commands and AI application. `label` names the document for accessibility. `onSave` is an optional application callback; `status` displays application-owned save status. The editor performs no persistence or automatic network requests.

Override strings with `labels` and styles with `views.container`, `toolbar`, `block`, `content`, `source`, `notice` and `panel`. On web, `content` styles the editable block; on native it styles the active field and inactive block container.

Native adapter and IME tests use host mocks; they do not validate a device keyboard. Web and native TypeScript checks and package builds pass.

The updated Cmd+A/C/X/V/Z/Shift+Z flow, formatting across blocks, floating toolbar surface and emoji insertion were verified in the Codex in-app browser. Arrow/Shift+arrow selection was also checked across blocks and code, including backward selection, reversal and wrapped visual lines. Literal multiline code entry and undo restored the original document. Enter/Backspace split and merge, their undo flow, list-item joins, Shift+Enter caret placement, link popover placement, address entry and Enter-to-apply were also verified in the in-app browser. The emoji icon's horizontal and vertical center match the button's center. These updates still need verification in Chrome, Firefox, Safari and on iOS/Android, including real IME and hardware keyboards.
